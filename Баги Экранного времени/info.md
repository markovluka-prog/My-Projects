- **Created:** 2026-06-01

## Description
Сборник из трёх уязвимостей в функции **Screen Time / Экранное время** на iPadOS,
найденных самостоятельно. Все три позволяют обойти ограничения Экранного времени
без знания родительского пароля. Цель проекта — оформить чёткий отчёт и отправить
в Apple (Apple Security Bounty / Feedback Assistant).

## Сводка багов
| # | Баг | Что позволяет | Статус |
|---|-----|---------------|--------|
| 1 | Обход пароля через «Упрощённый доступ» (Guided Access) | Всё доступно без пароля Screen Time, кроме блокировки сайтов | ✅ Исправлен Apple |
| 2 | Безлимитный сайт через полноэкранный режим | Пользоваться сайтом без лимита времени | ❌ Не исправлен |
| 3 | Нет лимита попыток ввода пароля Screen Time в потоке сброса | Полный перебор 4-значного кода (PoC готов) | ❌ Не исправлен |
