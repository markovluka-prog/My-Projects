## [1.0] — 2026-06-05
Первый собранный релиз (дата по mtime бандла `index-*.js`, сборка Vite).

### Добавлено
- Пошаговая тактическая боёвка на сетке; победа — захват замка.
- Кампания: 3 главы по легендам о короле Артуре (см. `story.txt`).
- 7 уровней ИИ: Новичок, Ученик, Боец, Воин, Тактик, Мастер, Легенда
  (minimax до глубины 4, адаптивная сложность у «Легенды»).
- Онлайн: комнаты по коду, очередь подбора, реванш, восстановление партии,
  обработка дисконнекта.
- Аккаунты через Supabase: регистрация email+пароль, вход, Google OAuth.
- Крафт оружия и брони из артефактов, система экипировки.
- Заклинания с башни мага (Кавалерийский натиск, Дождь защиты, Небо огня…).
- Обучающий режим (туториал).
- Инструменты: редактор карт, предпросмотр карт и спрайтов.
- Упаковка в macOS .app через SwiftHTMLRunner; PWA-манифест (standalone, landscape).
- Ассеты: Tiny Swords (Free Pack) + кастомные спрайты; музыка battle/hall.
