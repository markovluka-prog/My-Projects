# Рыцари и Замки — Описание

> Пошаговая тактическая браузерная игра по мотивам легенд о короле Артуре.

## Что это

«Рыцари и Замки» (англ. *Knights and Castles*, short name **K&C**) — пошаговая
тактическая стратегия на сетке. Игрок управляет отрядом средневековых юнитов,
захватывает вражеский замок, собирает артефакты, крафтит оружие и броню,
кастует заклинания с башни мага.

Игра написана на HTML5 / JavaScript (сборка Vite) и поставляется в трёх формах:
- как **браузерная игра / PWA** (manifest, standalone, landscape);
- как **десктоп-приложение для macOS** — HTML обёрнут нативным контейнером
  `SwiftHTMLRunner` (bundle id `com.lukamarkov.knightsandcastles`, версия 1.0,
  требует macOS 12.0+);
- предположительно как **iPad/Swift Playground** приложение (см. родственный
  проект AIO.swiftpm).

## Для кого

Игроки, любящие пошаговые тактики (в духе Advance Wars / Fire Emblem) с
артуровским сеттингом. Управление адаптировано под тач («Тапни своего воина,
чтобы выбрать его»), поддерживается и десктоп.

## Ключевые возможности

### Режимы игры
- **Сюжет** — одиночная кампания из 3 глав по легендам о короле Артуре
  (см. [context.md](context.md) → «Кампания»).
- **Онлайн** — сетевые матчи против другого игрока через комнаты по коду
  (создать / войти по коду), очередь подбора, реванш, восстановление партии
  после разрыва связи.
- **Обучение** — пошаговый туториал, обучающий базовым механикам.

### Боевая система
- Пошаговые бои на сетке: у каждого юнита ограниченное число активаций/ходов
  за ход («Осталось активаций», «Ходов осталось»).
- Победа достигается захватом вражеского замка
  («Победа игрока 1! Замок захвачен!»).

### Юниты
- **Рыцарь** / Меч — танковая пехота.
- **Лучник** и **Арбалетчик** — дальний бой (kite).
- **Конный / Кавалерия** — мобильный фланг, «Кавалерийский натиск».
- **Катапульта / Осада** — осадное оружие.
- **Самурай / Тяжёлая пехота** — ударная пехота.

### Экономика и предметы
- **Артефакты** — выпадают/находятся («Найден артефакт», в руинах).
- **Крафт** — оружие и броня создаются из артефактов
  (Кольчуга, Латы, Солнечный меч, Синий лук, Посох огня, Волшебная палочка…).
- **Экипировка** — оружие/броню можно надеть, снять, выбросить.

### Магия
- Заклинания доступны **только на башне мага**.
- Примеры: «Кавалерийский натиск», «Дождь защиты», «Небо огня».
- Расход артефактов; есть проверка достаточности ресурсов.

### Аккаунты (Supabase)
- Регистрация / вход по email + пароль (пароль ≥ 8 символов, подтверждение
  email по ссылке).
- Вход через **Google** (OAuth).
- Управление аккаунтом, выход.

## Инструменты разработчика (в комплекте)
- `map-editor.html` — **Редактор карт** (⚔️ Редактор карт).
- `map-preview.html` — предпросмотр карт.
- `sprite-preview.html` — предпросмотр спрайтов.

## Ассеты
- Тайлсет **Tiny Swords (Free Pack)** — юниты/здания/террейн/эффекты.
- Кастомные спрайты (`assets/custom/`): меч, лук, посох, логотип и т.д.
- Музыка: `battle.mp3` (бой), `hall.mp3` (меню/зал).
