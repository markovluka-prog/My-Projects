# ⚔️ Рыцари и Замки (Knights and Castles)

Пошаговая тактическая браузерная игра по легендам о короле Артуре.
HTML5/JS (Vite) + Supabase, упакована в macOS .app через SwiftHTMLRunner.

## Кратко
- **Режимы:** Сюжет (кампания, 3 главы), Онлайн (комнаты по коду), Обучение
- **ИИ:** 7 уровней (Новичок → Легенда), minimax + адаптивная сложность
- **Механики:** бой на сетке, захват замка, крафт/экипировка, заклинания
- **Бэкенд:** Supabase (Auth email/Google, онлайн-матчи)

> Источник истины по сюжету и ИИ — `story.txt` внутри бандла.
