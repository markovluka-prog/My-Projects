# Project Info

## General

- **Version:** 1.0.0
- **Status:** In Development

## Description
Все важные приложения в одном месте. Для взрослых, которые устали переключаться между вкладками. Создание и поддержка полностью бесплатны. У каждого раздела снизу всегда виден баннер с названием источника данных.

## Platform
- **Type:** Application
- **Platform:** iOS (Swift Playgrounds)
- **Language / Stack:** Swift + WKWebView + HTML/CSS/JS

## Audience
- **Target Users:** Взрослые, которым нужно много сервисов сразу
- **Use Case:** Заменить десятки приложений и вкладок одним

## Notes
- Контент фильтруется по возрасту — пользователь указывает возраст в настройках, и приложение скрывает всё что не подходит
- Все источники данных — бесплатные (RSS, открытые API, VK Video, YouTube и т.п.)
- ИИ-проводник помогает найти нужный раздел или функцию голосом или текстом
- Пользователь сам выбирает какие разделы ему нужны
