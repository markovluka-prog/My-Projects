# AIO — All In One

## Что это
Все важные приложения в одном месте. Для взрослых, которые устали переключаться между вкладками и приложениями. Создание и поддержка полностью бесплатны. Разработчик — 12 лет, поэтому никакого дурного контента из интернета. У каждого раздела снизу всегда виден баннер с названием источника данных.

## Как работает
- При открытии — главное меню с боковой панелью
- Боковая панель: в главном меню всегда на экране, в остальных разделах выезжает по нажатию
- Боковая панель содержит: настройки пользователя (возраст, имя — влияют на фильтрацию контента) и ИИ-проводник (работает как Siri — голос или текст, помогает найти раздел или функцию)
- Пользователь сам выбирает какие разделы ему нужны — в отдельном меню выбора

## Разделы

### 📝 Записи
Стиль: зелёный + жёлтый, библиотека. Логотип: жёлтый карандаш на голубом фоне с чёрным грифелем и двумя жёлтыми крестиками по углам.
- Справа — книжный шкаф со скроллом. Полки = папки, книги = записи
- У каждой книги значок вида: 🧾 список, ✅ форма, 📝 обычная
- Шрифт всех записей — рукописный (Chalkboard SE)
- Кнопка «Выбрать» → выбрать несколько → удалить / экспортировать / распечатать (PDF)
- **Список:** заголовок + подзаголовок, пункты с галочками, к каждому можно прикрепить картинку или ссылку, новые пункты добавляются автоматически при переходе на строку
- **Форма:** заголовок + подзаголовок, вопросы кнопкой +. Три вида вопросов: вариант с картинкой, текстовый ответ, вариант с текстом. Два типа форм: квиз (правильные ответы) и обычная (сохранение ответов). Экспорт в HTML на сервер по ссылке, ответы приходят прямо под формой
- **Обычная запись:** свободный текст с абзацами и картинками. Схемы трёх видов: диаграммы, пошаговые инструкции, схематичные картинки из символов

### ⏱️ Тайм-менеджер
Стиль: бело-голубой. При открытии без активных инструментов — логотип по центру и три картинки снизу: таймер, будильник, календарь.
- **Таймер:** стиль Атлантиды. Древний город с концентрическими кольцами, на который надвигается цунами. Сверху две молнии, между ними — золотое время. Нажатие на центр = старт/пауза. На стене центра написано что сделает следующее нажатие. Кнопки отменить нет — сбросить нельзя. Время выставляется скроллом цифр
- **Будильник:** стиль Древнего Китая. Человек + гонг справа, в гонг летит стрела — долетает ровно в момент срабатывания. Кнопка + над колонной = новая стрела. У каждой стрелы — информационное табло с временем, названием (пишется на стреле) и повтором. Если скоро — летит быстрее. Двойное нажатие на стрелу = удалить (сломается и исчезнет)
- **Календарь:** стиль морского порта. Название порта = текущий год, между годами — взмахи. 12 пристаней = 12 месяцев. На пристанях — причалы с датами, корабли с ящиками = события. Ящики: золотой / серебряный / бронзовый по приоритету. Наклейка на ящике: название, дата, заметки + кнопки отменить / изменить / удалить. Создать событие: кнопка + у причала, приплывает корабль или удлиняется текущий

### 🌤️ Прогноз погоды
Стиль: бело-синий. Данные = среднее с 5 лучших метеослужб в данном месте.
- По умолчанию — геолокация, место меняется вручную сверху
- Прогноз на неделю — иконки погоды + температура от min (синяя) до max (красной). Целые числа. Нажатие на день = почасовой график
- УФ-индекс, ветер, качество воздуха, давление (пониженное/обычное/повышенное + растёт/падает/стабильно)
- Карта мира с фильтрами по параметрам (температура, ветер, осадки, УФ, качество воздуха)

### 🎬 Фильмы
Источники: VK Video, YouTube и похожие бесплатные платформы. Фильм запускается в мини-браузере поверх которого накладывается дизайн AIO.
- Каждый фильм — кораблик
- Главный экран: поиск (табличка сверху) + персональные предложения (иллюминаторы — круглые окошки с логотипом)
- При нажатии на фильм: информационное табло (генерируется ИИ) + кнопки «Назад» и «Смотреть»
- Во время просмотра нажатие = кнопка назад, пауза/воспроизведение, прогресс (река с корабликом), флаг с качеством/языком/названием. Качество и язык меняются во время просмотра

### 🗞️ Новости
Стиль: бежево-чёрный, газетный. Источники: бесплатные RSS-ленты.
- Раздел = газетный киоск с тремя газетами: 🌍 Мир, 🔬 Наука, 💻 Технологии
- Факт дня: жёлтая карточка с лампочкой — ИИ пересказывает самую интересную новость одним предложением
- Внутри газеты: список заголовков (текст, дата, источник). Нажатие = мини-браузер с оригинальной статьёй
- Фильтры: Мир → 🗺️Политика / 🌿Природа / 🏙️Общество; Наука → 🧬Биология / 🚀Космос / ⚛️Физика; Технологии → 🤖ИИ / 📱Гаджеты / 🎮Игры

### 🎮 Игры
Стиль: яркий, пёстрый, ярмарочный. Игры открываются в мини-браузере с официального сайта.
- Ярмарка с палатками — каждая палатка = жанр игр
- Поисковая строка над входом — ИИ подбирает нужные палатки и игры
- Прогресс сохраняется на аккаунте пользователя (как CrazyGames)

### 💰 Финансы
Стиль: тёмно-зелёный + золотой. Банковское хранилище с дверью-сейфом.
- Категории расходов = ячейки в хранилище с замочком и суммой
- Нажатие на ячейку = список трат внутри
- Добавить трату: кнопка + у входа (сумма, категория, заметка)
- Статистика: весы над сейфом — слева доходы, справа расходы

### 🌐 Переводчик
Стиль: кирпично-бежевый, Вавилонская башня. Ярусы = языки (выше = популярнее).
- Ввод у подножия башни, перевод — на каменной плите сбоку
- Выбор языка = нажатие на ярус
- Перевод текста, голоса и фото с текстом. Мгновенно

### 🖩 Калькулятор
Стиль: серо-стальной, завод с шестерёнками. Каждая шестерёнка = операция.
- Цифры вводятся на пульте оператора по центру
- История вычислений = лента конвейера слева (прокручивается вниз)
- Конвертер валют и единиц = отдельный цех справа. Курсы обновляются автоматически

### 👨‍👩‍👧 Семейный режим
Стиль: тёплый, деревянный, деревня с домиками. Каждый участник = домик с именем.
- Внутри домика: общий календарь (доска у колодца), список покупок (корзина у рынка), общие заметки (доска у входа)
- Все изменения видны всем в реальном времени
- Добавить участника = посадить новый домик

### 🍽️ Рецепты
Стиль: тёплый, зелёно-коричневый, деревенский рынок. Лотки = категории ингредиентов.
- Нажимаешь на ингредиенты которые есть → они перекладываются в корзину → рынок показывает что приготовить
- Каждый рецепт = свиток с названием, временем и шагами (рукописный шрифт)
- Избранное = личный погреб в углу экрана

### 🏃 Трекер привычек
Стиль: зелёный, сад с грядками. Каждая грядка = привычка.
- Отметил привычку = растение растёт и цветёт
- Пропустил день = чуть вянет, несколько дней = засыхает (но можно восстановить)
- Добавить привычку = посадить семя, написать название и частоту
- Статистика = вид всего сада

### 📄 Документы
Стиль: бежево-синий, почтовый. Документы = письма и конверты в почтовом ящике.
- Сканировать = бросить в прорезь ящика. Камера обрезает края, сохраняет в PDF
- Подписать = сургучная печать на конверт
- Подписанные документы = раздел «Отправлено» (отдельное отделение ящика справа)

### 🎵 Музыка
Стиль: бордово-золотой, концертный зал. Источники: VK Музыка, YouTube.
- Концертный зал с рядами кресел и сценой
- Афиши на стенах = персональные рекомендации
- Сцена = текущий трек (нарисован исполнитель, прогресс = занавес)
- Поиск = билетная касса у входа. Результаты = билеты с названием и исполнителем
- Музыка открывается в мини-браузере, логотип источника виден снизу

## Дизайн
- Каждый раздел имеет свою уникальную тему и стиль
- Снизу всегда виден баннер с источником данных
- ИИ-проводник доступен из любого места через боковую панель
- Контент фильтруется по возрасту пользователя

## Технологии
- Swift Playgrounds + WKWebView — обёртка
- HTML / CSS / JS — весь интерфейс и логика
- ИИ — проводник, описания фильмов, факт дня, подбор игр
- RSS — новости
- Открытые метеоAPI — погода
- VK Video, YouTube — фильмы и музыка
