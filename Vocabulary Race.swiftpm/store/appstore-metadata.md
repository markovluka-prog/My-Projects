# App Store — метаданные (черновик)

Готовится к загрузке в App Store Connect. Лимиты Apple указаны в скобках.

## Основное
- **Название (30):** Vocabulary Race
  - Альтернатива (рус): `Словарная Гонка`
- **Подзаголовок (30):** Слова и гонка для 2–4
- **Категория:** Игры → Словесные (Word). Вторичная: Головоломки (Puzzle)
- **Возрастной рейтинг:** 4+
- **Цена:** Бесплатно (без рекламы, без покупок) — *подтвердить*

## Ключевые слова (100 символов, через запятую, без пробелов)
```
слова,словесная,гонка,настольная,семья,буквы,словарь,эрудит,вечеринка,2 игрока,бродилка,русский,offline
```
(57 символов с латиницей — можно добить синонимами: `word,party,family,board,letters`)

## Промо-текст (170)
```
Составляй слова из букв карточки, кидай кубик и гони фишку по треку. Первый до финиша побеждает! 2–4 игрока на одном устройстве + умные боты.
```

## Описание (4000)
```
🏁 Vocabulary Race — это словесная настольная гонка для всей семьи и компании друзей!

Составляй слова из букв выпавшей карточки, бросай кубик и двигай свою фишку по гоночному треку. Кто первым доберётся до финиша — тот и чемпион.

⚡ КАК ИГРАТЬ
• Брось кубик — узнаешь, сколько слов нужно составить
• Собери слова из букв карточки за 60 секунд
• Успел — фишка мчит вперёд. Не успел — откат назад
• Лови спец-карты: «Гонщик» рвёт вперёд без задания, «Судья» отбирает очки у соперника
• Первый до финиша выигрывает гонку!

👨‍👩‍👧‍👦 ДЛЯ КОМПАНИИ
• От 2 до 4 игроков на одном устройстве (hot-seat)
• Играй против друзей или против ботов
• Экран-заглушка между ходами — никто не подсмотрит твои слова

🤖 УМНЫЕ БОТЫ
• Три уровня сложности: Лёгкий, Средний, Сложный
• Можно смешивать людей и ботов в любой комбинации

📚 БОЛЬШОЙ СЛОВАРЬ
• Более 26 000 русских слов
• Проверка слов в реальном времени

🎮 ОСОБЕННОСТИ
• Полностью офлайн — интернет не нужен
• Звуковое сопровождение (можно выключить)
• Анимации, конфетти, 3D-кубик
• Никакой рекламы и встроенных покупок

Собери компанию и устрой словесную гонку! 🏆
```

## App Privacy (анкета в App Store Connect)
- **Сбор данных:** Нет (offline-версия). → «Data Not Collected»
- ⚠️ При добавлении онлайн-режима (Supabase) пересмотреть: коды комнат, никнеймы — указать как не связанные с личностью, не для трекинга.
