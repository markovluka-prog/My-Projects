# Changelog — Vocabulary Race

Что менялось в каждой версии. Новое сверху.

---

## v3.2-beta — 2026-06-08
Двуязычность RU/EN.
- **[ЯЗЫК]** Полная локализация: интерфейс + слова. Кнопка-переключатель RU/EN в меню (слева вверху), выбор сохраняется
- **[ЯЗЫК]** Английский словарь `dictionary_en.txt` (Scrabble TWL, ~113k слов, длина 2–9)
- **[ЯЗЫК]** Движок i18n: таблица переводов + `t()` + `data-i18n`; склонения слов/клеток/очков по языку
- **[ЯЗЫК]** Ленивый парсинг словарей (на старте — только текущий язык) + защита от двойной загрузки (fetch/Swift) — устранены подвисания старта
- **[Swift]** `ContentView`/`MyApp` инжектят оба словаря через `__injectDict(lang, text)`

## v3.1-beta — 2026-06-07
Наблюдение за соперником, пауза-меню, чистая колода.
- **[ОНЛАЙН]** Живой просмотр хода соперника: пассивный игрок видит кубик, буквы и составляемые слова в реальном времени (broadcast `dice`/`spect`)
- **[ОНЛАЙН]** Статус соперника в шапке: 🟢 в сети / 🔴 не в сети (presence)
- **[ИГРА]** Пауза-меню (☰): «Продолжить», «Закончить партию» (итоговая таблица), «Выход в меню»; в онлайне — выход из комнаты
- **[ИГРА]** В колоду попадают только слова, из которых реально можно составить ≥ нужного числа слов (валидация по словарю при выдаче)
- **[ИГРА]** Подсказка при провале теперь точная (поиск по всему словарю)
- **[macOS]** Universal-сборка (Intel x86_64 + Apple Silicon arm64)

## v3.0-beta — 2026-06-07
Онлайн-режим, звук, видимость карт и фиксы.
- **[ОНЛАЙН]** Сетевая игра на 2 игроков через Supabase Realtime (Broadcast + Presence), комнаты по 4-значному коду, канал `vr-room-<КОД>`, без таблиц/RLS
- **[ОНЛАЙН]** Синхронизация очков, хода и спец-карт; обработка отключения соперника («Вы победили!»)
- **[ОНЛАЙН]** Библиотека `supabase-js` лежит локально (`GameWeb/lib/supabase.js`), без CDN
- **[ОНЛАЙН]** Случайная игра — подбор соперника через общий лобби-канал `vr-lobby` (presence + broadcast)
- **[ПРОДОЛЖЕНИЕ]** Локальная партия сохраняется в localStorage после каждого хода; кнопка «▶️ Продолжить партию» в меню
- **[КАРТЫ]** Спец-карты обоих игроков видны в табло; уведомление когда соперник использует карту
- **[ЗВУК]** Звуковое сопровождение (Web Audio синтез): кубик, шаги, успех/провал, карта, слово, ошибка, победа; кнопка 🔊/🔇 в меню с сохранением
- **[БОТ]** Сила бота = чистая вероятность (😊 0.40 / 😐 0.65 / 🔥 0.90), 3 уровня, независимо от кубика/словаря
- **[ФИКС]** Кубик: грани 3 и 4 показывались наоборот (неверный знак rotateX)
- **[ФИКС]** Краш `ReferenceError` при ресайзе/повороте (мёртвый `debugMode`)
- **[ФИКС]** После победы ход больше не «проскакивает» (флаг `gameOver`)
- **[ФИКС]** Кнопки спец-карт в руке теперь кликабельны и используют выбранную карту
- **[СТОР]** Папка `store/`: метаданные листинга, privacy-policy.html, support.html

## v1.5 — 2026-03-10
Исправление багов.
- **[КРИТ]** Токены теперь позиционируются через `getBoundingClientRect` — исправлено смещение из-за `object-fit:contain` (letterboxing)
- **[КРИТ]** Фишки перепозиционируются при изменении размера/повороте экрана (resize listener)
- Экраны: добавлен fade-out (класс `.leaving` теперь применяется при переходе)
- Анимации result-emoji и кнопки «Продолжить» теперь воспроизводятся каждый ход
- Защита от двойного вызова `finishTask` (таймер + сабмит одновременно)
- Тост: сброс анимации перед повторным показом
- Карточка судьи: кнопка «Продолжить» появляется после движения ОБОИХ игроков (было только одного)

## v1.4 — 2026-03-10
Словарь расширен до 26,245 слов.
- Новый источник: Badestrand/russian-dictionary (GitHub), nouns.csv
- Фильтр: первая буква строчная = нарицательное (убраны 399 собственных: Москва, Россия и т.д.)
- Только [а-яё]+, длина 2–21 букв, дедупликация
- Итог: 26,245 нарицательных существительных (было 891)
- Для карточек (≥ 7 букв): 18,677 слов
