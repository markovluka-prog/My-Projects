## Суть теории
Гравитация порождается протонами. Каждый протон — пружина (сила растёт с расстоянием внутри своего поля). Миллиарды протонов вместе дают убывающую концентрацию полей → формула 1/k² (как у Ньютона). Главное отличие: поле **конечное** — за k_макс гравитации нет.

## Формулы
- **Ф1а (протон):** `F = G·m·mₚ·k / rₚ³` при k ≤ rₚ — пружина
- **Ф1 (планета):** `F = G·m·b / k²` при k ≤ k_макс — Ньютон с обрывом
- **Ф2 (поле):** `k_макс = C·r·√m`, C = 2.469×10⁻¹¹

## Проверки
- Поверхностное g всех планет: ошибка < 0.1% ✅
- МКС орбита: ошибка 0.2% ✅
- Луна орбита: ошибка 0.4% ✅
- Орбиты Меркурий/Земля/Нептун вокруг Солнца: ошибка < 1% ✅
- k_макс Земли = расстояние до Луны ✅
- k_макс Солнца = облако Оорта (162 АЕ) ✅

## Отличия от Ньютона/Эйнштейна
1. Поле конечное (k_макс) — у них бесконечное
2. Механизм другой: протоны-пружины, а не "масса притягивает массу"
3. Гравитация управляема через антигравитон (e-)
