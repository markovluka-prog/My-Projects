# Easter Maze

## Что это
3D лабиринт от третьего лица с реалистичной графикой. Цели нет — просто ходишь, трогаешь всё вокруг и натыкаешься на пасхалки. Каждый угол может оказаться не тем, чем кажется.

## Как работает
- Игрок видит героя сзади, камера следует за ним
- Лабиринт состоит из зон с разным окружением (лес, здание, подземелье, луг и др.)
- В каждой зоне спрятаны пасхалки — секретные комнаты, неожиданные события, интерактивные объекты
- Есть враги и ловушки — можно умереть, возрождаешься на месте смерти
- Никакого финала — игра про исследование

## Управление
- **W / стрелка вверх** — идти вперёд
- **Свайп** — поворот камеры / направления
- **Нажатие** — взаимодействие с объектами / прыжок

## Пасхалки (известные)

### 1. Петля со стрелками
- Стрелка 1: «Иди вперёд» → идёшь вперёд
- Стрелка 2: «Иди налево» → идёшь налево
- Стрелка 3: «Иди сюда» (показывает налево) → идёшь
- Стрелка 4: приводит обратно к старту — так, что ты этого не замечаешь
- **Выход:** пройти прямо сквозь стену со стрелкой «Иди сюда»

### 2. Луг с тремя озёрами
- Маленькая лужайка: 2 озера с водой, 1 с лавой
- Прыжок в воду → начинает убывать здоровье, возрождаешься на лугу
- **Выход:** прыгнуть в озеро с лавой → проваливаешься насквозь на следующий уровень

## Дизайн
- Стиль: реализм
- Зоны смешанные: природа, постройки, подземелья
- Атмосфера: тихая, но с ощущением что что-то не так

## Технологии
- Swift Playgrounds + WKWebView — обёртка
- HTML / CSS / JS — весь интерфейс и логика игры
